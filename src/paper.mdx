## Overview

**AURASim** is a research-oriented simulation framework for high-fidelity **automotive FMCW radar** based on **ray tracing** and **digital-twin scene modeling**. The goal is to connect physically meaningful scene geometry and material interactions with radar-specific signal generation, enabling end-to-end experiments from propagation paths to ADC samples, range-Doppler processing, MIMO sensing, and dynamic-scene effects such as local motion and micro-Doppler.

</HighlightedSection>

## Motivation

Modern automotive radar simulation needs more than a list of idealized point targets. Real scenes contain extended objects, multipath, occlusion, material-dependent reflection, diffuse scattering, articulated motion, rotating components, and dense MIMO arrays. AURASim is designed as a modular framework in which these effects can be studied in a common pipeline.

The current implementation uses **Sionna RT** as the propagation engine while extending the surrounding simulation stack toward radar-specific requirements.

### Digital-Twin Scene

AURASim represents static and dynamic environments with explicit geometry, object motion, materials, radar poses, and antenna configurations. The simulator is intended to support both rigid-body motion and more complex articulated or locally varying motion.

### Ray-Tracing Propagation

The propagation layer discovers physically meaningful multipath interactions between radar transmitters, scene objects, and receivers. Current research focuses on the behavior and scalability of specular reflection, diffuse scattering, path sampling, and path truncation in dense radar scenes.

### Automotive FMCW Signal Generation

Propagation paths are converted into radar-domain signals rather than being used only as communication channels. The signal layer is intended to model chirps, delays, phase evolution, Doppler, MIMO channels, ADC sampling, and downstream FFT-based radar processing.

### Dynamic Motion and Micro-Doppler

A key focus is local motion. A single object-level velocity is insufficient for effects such as swinging limbs or rotating wheels. AURASim is therefore exploring efficient strategies that preserve detailed motion information while avoiding full ray tracing for every chirp.

## Key Research Questions

- How can large numbers of ray-traced propagation paths be retained without destabilizing radar observables?
- How should specular and diffuse-scattering paths be sampled and truncated for radar rather than communications?
- How can dynamic hitpoints be tracked efficiently across FMCW chirps?
- How can local surface velocity and micro-Doppler be modeled without running a full ray-tracing solve for every chirp?
- How can one reference ray-tracing solution be reused efficiently across large MIMO transmit/receive arrays?
- How closely can a scalable simulator reproduce a high-fidelity chirp-level ray-tracing reference?
